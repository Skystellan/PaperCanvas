# 论文内嵌 ChatGPT 验证

2026-09-16，macOS 本地 debug 应用。

## 已验证

- 阅读器右侧 AI chat 按当前论文显示讨论列表。
- 新建讨论能写入本地数据库，退出并重新打开应用后可恢复。
- 原生子 WebView 在 PDF 右侧加载 ChatGPT，显示登录按钮和输入框。
- 切换 Notes 会隐藏网页，切回 AI chat 恢复网页。
- 修复 macOS 原生 frame 与 DOM viewport 的标题栏高度差：按实际视口高度转换坐标，网页不再覆盖绑定状态文字。
- 相关前端回归测试 40 项通过；Rust URL 校验和论文讨论隔离/排序/级联删除测试 2 项通过。坐标修改后重跑新增前端测试 4 项与 Rust 测试 2 项，均通过。
- TypeScript、ESLint、前端构建和 macOS debug 应用打包通过。

## 登录后的实机验证

- 用户完成内嵌登录后，发送了一条“请只回复已收到”的测试消息，收到对应回复。
- 网页从临时 WEB 地址切换到正式 conversation UUID 后，App 自动保存链接，讨论显示已绑定。
- 完全退出并启动新构建后，登录仍有效，打开该论文可恢复同一聊天及其回复。
- 在同篇论文下另建了“公式推导”讨论；两个本地讨论条目均可见。
- 第三方登录弹窗流程未单独验证。

## 紧凑阅读器布局

- 移除应用内 PaperCanvas / Local data 品牌栏。
- Notes、Mind map、AI chat 标签，以及讨论选择和操作按钮移到 Hide panel 同一顶栏。
- 聊天侧栏移除重复标题、外框、说明文字和内边距，只保留网页区域。
- 在相同窗口尺寸下，网页可用高度由约 375 逻辑像素增加至约 719。
- 本轮相关前端测试 32 项通过；TypeScript、ESLint 与 macOS debug 打包通过。

本地仅保存论文与讨论名称、URL 的关联。聊天正文留在 ChatGPT，未实现离线消息副本。

## 2026-09-18：一键新建与标题同步

- 加号直接创建并选中“新对话”，不再要求输入名称。
- 使用原生 document-title-changed 事件同步已绑定 ChatGPT 页面的标题。
- 通用 ChatGPT 标题、空标题和其他对话的标题不会覆盖当前绑定。
- 前端相关测试 4 项、Rust 相关测试 3 项通过；此轮未实机重发消息验证标题事件。
