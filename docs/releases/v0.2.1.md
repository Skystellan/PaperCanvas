# PaperCanvas v0.2.1 — Steadier hubs, lasting drop positions

拖动小节点时，枢纽节点更稳；松手后，拖动的节点保持落点。

## Changes / 更新

- **More inertia for connected hubs.** Nodes with more connections resist acceleration, so dragging a leaf has less influence on the whole network. Directly dragged cards still follow the pointer.
  **枢纽节点更稳。** 根据连线数量增加惯性，减少小节点拖动对大节点的影响。
- **Keep your drop point.** A dropped card stays in place while its neighbors settle. Dragging preserves existing spring lengths instead of pulling the network back toward a compact layout. A new drag or explicit re-layout can move the card again.
  **松手不再明显回退。** 保留当前连线长度，松手后暂时保持落点，让周围节点继续整理；下一次拖动或主动整理仍可调整布局。
- **Preserve domain behavior.** Backgrounds continue to wrap their cards, and neighboring regions move aside smoothly. Multi-selection and connections saved after pointer-up retain the drop positions.
  **保持分区交互。** 背景继续随节点伸缩，相邻区域整体让开；多选拖动和连线异步保存也保留落点。

## Download and install / 下载安装

**Apple Silicon (M1 or newer), macOS 13+.** Download `PaperCanvas-0.2.1-macOS-arm64.zip`, unzip, and move `PaperCanvas.app` to Applications. Quit the previous app before replacing it. Your library, notes, and settings stay in their separate data directory.

退出旧版后替换应用即可，已有论文、笔记与设置会保留。本版本不包含 Intel Mac、Windows 或 Linux 安装包。

This build is ad-hoc signed, without an Apple Developer ID or notarization. If macOS blocks the first launch and you trust this download, use **System Settings → Privacy & Security → Open Anyway** after attempting to open it. [Apple's instructions](https://support.apple.com/en-us/102445).

首次启动如被 macOS 拦截，请在确认下载来源后，前往「系统设置 → 隐私与安全 → 仍要打开」。本版本尚未经过 Apple 公证。
