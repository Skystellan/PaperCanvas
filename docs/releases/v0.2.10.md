# PaperCanvas v0.2.10 — Connection notes and colors

Click a connection to edit its color and annotation in one dialog. The dialog now matches the main window's glass styling, with a single annotation field. Existing evidence remains stored, and annotation drafts still survive selection changes and save before opening the reader.

点击连线即可在「连线备注」中选择颜色、编辑批注。弹窗统一为主页面的磨砂玻璃风格，输入区仅保留「批注」；历史证据数据仍保存在本地。切换选择保留草稿，进入阅读器前自动保存。

## Install and update / 安装与更新

Linux DEB/AppImage, Windows Setup and macOS users can upgrade from **Help → Check for Updates…**. Local papers, notes and sign-in data are preserved. Windows portable ZIP users upgrade manually. The macOS community build is ad-hoc signed; Windows is unsigned. First-launch operating-system prompts still apply.

Linux DEB/AppImage、Windows 安装版和 macOS 均可通过 **帮助 → 检查更新** 升级，本地论文、笔记和登录资料会保留。0.2.9 正式版及测试包均可升级至本版本。Ubuntu 20.04 上无法启动的 0.2.8 用户，请直接下载安装 DEB：

```sh
sudo apt install ./PaperCanvas-0.2.10-Linux-amd64.deb
```

Linux continues to support Ubuntu 20.04 / 22.04 / 24.04 x64 with a glibc 2.31 baseline. [Ubuntu 20.04 兼容说明](https://github.com/Skystellan/PaperCanvas/blob/v0.2.10/docs/ubuntu-20.04.md)

## Validation / 验证范围

The release workflow covers frontend and Rust tests, packaged Windows/macOS desktop tests, Ubuntu 20.04 DEB/AppImage desktop and update tests, and the same Linux packages on Ubuntu 22.04/24.04. The connection workflow verifies color persistence, annotation saving, historical evidence retention and keyboard deletion.

发布流程覆盖三平台桌面测试及 Ubuntu 20.04 / 22.04 / 24.04 兼容与更新测试；连线流程验证颜色持久化、批注保存、历史证据保留和键盘删除。

`SHA256SUMS.txt` covers the release files. `latest-linux.yml`, `latest.yml`, `.blockmap` and signed `appcast.xml` are updater files; ordinary installation does not require downloading them.
