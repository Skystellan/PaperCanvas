# PaperCanvas v0.2.11 — PDF paper titles

Imported PDFs now use their embedded title instead of relying on the filename. When metadata is missing or clearly invalid, PaperCanvas tries to identify the title on the first page, including multiline headings. Files named with an arXiv identifier can therefore display the paper's title in the library and on the whiteboard.

导入 PDF 时优先读取文件内嵌的论文标题；元数据缺失或明显无效时，尝试识别首页标题，包括多行标题。以 arXiv 编号命名的 PDF 也可以在论文库和白板中显示论文标题。

Title recognition runs locally without network access. If recognition or saving the title fails, the import still succeeds with the filename. Scanned PDFs without a text layer fall back to the filename unless they contain a usable metadata title. Previously imported titles are not changed automatically.

标题识别完全在本地运行，无需联网。识别或保存标题失败时仍会完成导入，并保留文件名作为标题。没有文字层且没有有效内嵌标题的扫描件仍使用文件名。已收录论文的标题不会自动更改。

## Install and update / 安装与更新

Linux DEB/AppImage, Windows Setup and macOS users can upgrade from **Help → Check for Updates…**. Local papers, notes and sign-in data are preserved. Windows portable ZIP users upgrade manually. The macOS community build is ad-hoc signed; Windows is unsigned. First-launch operating-system prompts still apply.

Linux DEB/AppImage、Windows 安装版和 macOS 均可通过 **帮助 → 检查更新** 升级，本地论文、笔记和登录资料会保留。Windows 便携版请手动替换程序。

## Validation / 验证范围

Regression tests parse generated PDFs to verify Unicode metadata, XMP titles, multiline headings, invalid-title fallback and rotated arXiv margin labels. Import tests verify title persistence and successful imports when recognition or saving fails. The desktop workflow covers frontend and Rust tests, packaged Windows/macOS tests, Ubuntu 20.04 DEB/AppImage desktop and update tests, and compatibility with Ubuntu 22.04/24.04.

回归测试通过解析实际生成的 PDF，验证 Unicode 元数据、XMP 标题、多行标题、无效标题回退及页边旋转的 arXiv 标识；导入测试验证标题持久化，以及识别或保存失败不影响导入。桌面发布流程覆盖三平台测试和 Ubuntu 20.04 / 22.04 / 24.04 兼容与更新测试。

`SHA256SUMS.txt` covers the release files. `latest-linux.yml`, `latest.yml`, `.blockmap` and signed `appcast.xml` are updater files; ordinary installation does not require downloading them.
