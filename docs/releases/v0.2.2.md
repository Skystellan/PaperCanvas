# PaperCanvas v0.2.2 — Recover overstretched connections

修复 v0.2.1 中拖动后连线过长、持续拖动可能越拉越长的问题。

## Fix / 修复

The previous release accepted the entire stretched distance as a connection's new natural length. Cooling weakened its restoring force further while readability forces could still push cards apart.

This patch bounds the accepted natural length and keeps a gentle restoring force for excessively stretched connections throughout cooling. Nodes move smoothly instead of snapping to a distance limit. Hub inertia, drop-point retention, expanding backgrounds, and separate domain groups remain in place. Cross-domain connections do not pull groups together.

现在会限制弹簧接受的自然长度，并在冷却和连线避让期间持续柔性回收过长连线。保留大节点惯性、松手落点和分区整体避让，逐帧限制速度，避免突然跳变。

Existing saved arrangements are preserved on launch. Drag a card or use **重新整理布局** to shorten existing stretched connections.

已有布局不会在启动时重排；轻拖当前区域内的节点，或点击「重新整理布局」，即可回收已有的过长连线。

## Download / 下载

**Apple Silicon (M1 or newer), macOS 13+.** Download `PaperCanvas-0.2.2-macOS-arm64.zip`, quit the previous app, and replace it with the unzipped `PaperCanvas.app`. Your library, notes, and settings remain in their separate data directory.

退出旧版后替换应用即可，已有论文、笔记和设置会保留。本版本不包含 Intel Mac、Windows 或 Linux 安装包。

This build is ad-hoc signed, without an Apple Developer ID or notarization. If macOS blocks the first launch and you trust this download, use **System Settings → Privacy & Security → Open Anyway** after attempting to open it. [Apple's instructions](https://support.apple.com/en-us/102445).

首次启动如被 macOS 拦截，请在确认下载来源后，前往「系统设置 → 隐私与安全 → 仍要打开」。本版本尚未经过 Apple 公证。
