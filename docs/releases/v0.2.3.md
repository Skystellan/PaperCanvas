# PaperCanvas v0.2.3 — Keep the shape around a dragged hub

拖动枢纽节点后，保留邻居围绕它的原有方位，减少星形网络被拖成一侧的现象。

## Fix / 修复

Distance springs alone let neighbors fall behind a moving hub and settle on the wrong side. Hub dragging now remembers the initial directions of its less-connected immediate neighbors in the same domain. A gentle turning force preserves those directions during dragging and cooling, while connection lengths remain free to adjust for readability and collisions.

现在会记住拖动开始时邻居位于枢纽的哪个方向，并在拖动和松手整理期间平滑保持这个方位。连线距离仍可伸缩，大节点惯性、松手落点、长线回收和分区避让继续生效。拖动叶子节点不会触发整圈方位约束；跨区域连线也不会把分区拉到一起。

The reference is the arrangement at the start of each drag. This preserves an existing structure; it does not restore a historical layout that has already been changed. Explicit re-layout remains available.

以每次拖动前的布局为基准，不会恢复已经丢失的历史位置；仍可使用「重新整理布局」重新排布。

**Apple Silicon (M1 or newer), macOS 13+.** Download `PaperCanvas-0.2.3-macOS-arm64.zip`, quit the previous app, and replace it with the unzipped `PaperCanvas.app`. Your library, notes, and settings remain in their separate data directory.

退出旧版后替换应用即可，已有论文、笔记和设置会保留。本版本不包含 Intel Mac、Windows 或 Linux 安装包。

This build is ad-hoc signed, without an Apple Developer ID or notarization. If macOS blocks the first launch and you trust this download, use **System Settings → Privacy & Security → Open Anyway** after attempting to open it. [Apple's instructions](https://support.apple.com/en-us/102445).

首次启动如被 macOS 拦截，请在确认下载来源后，前往「系统设置 → 隐私与安全 → 仍要打开」。本版本尚未经过 Apple 公证。
