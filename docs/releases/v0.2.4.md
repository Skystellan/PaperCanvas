# PaperCanvas v0.2.4 — Compact layouts with room to read

静止和松手后的网络更紧凑，同时保留卡片间距、枢纽周围的环绕结构和拖动落点。

## Layout / 布局

Connections now gently contract toward their natural length throughout cooling, instead of only recovering extreme stretches. Stronger recovery still handles very long connections. Peripheral cards carry more of the adjustment, while a deliberately placed leaf can retain extra length without pulling its heavier hub across the canvas.

普通偏长的连线会温和收紧，严重拉长的连线仍会加快恢复。紧凑化在松手后进行，外围节点承担更多调整；手动拉开的叶子节点保留适度伸展空间，减少对大节点的牵动。卡片避让、连线互斥、分区整体避让和拖动后的方位保持继续生效。

In fixed regression fixtures, the mean connection length after releasing a loose star falls from 643 to 452 canvas units; a two-hub network falls from 672 to 483. These are fixture results, not a guarantee for every graph. Crowded hubs and connections between clusters can remain longer to preserve readable spacing.

固定测试中，松散星形网络松手后的平均连线从约 643 缩短至 452，双中心网络从约 672 缩短至 483。不同结构会得到不同结果；拥挤枢纽和团簇之间的连线仍允许适当伸长。

Existing saved layouts stay in place when opened. Drag a node or choose **重新整理布局** to apply the new balance. This release reuses the existing force layout and adds no layout dependency.

已保存的布局不会在打开时被自动重排。拖动节点，或点击「重新整理布局」，即可应用新的紧凑化规则。

## Download / 下载

**Apple Silicon (M1 or newer), macOS 13+.** Download `PaperCanvas-0.2.4-macOS-arm64.zip`, quit the previous app, and replace it with the unzipped `PaperCanvas.app`. Your library, notes, and settings remain in their separate data directory.

退出旧版后替换应用即可，已有论文、笔记和设置会保留。本版本不包含 Intel Mac、Windows 或 Linux 安装包。

This build is ad-hoc signed, without an Apple Developer ID or notarization. If macOS blocks the first launch and you trust this download, use **System Settings → Privacy & Security → Open Anyway** after attempting to open it. [Apple's instructions](https://support.apple.com/en-us/102445).

首次启动如被 macOS 拦截，请在确认下载来源后，前往「系统设置 → 隐私与安全 → 仍要打开」。本版本尚未经过 Apple 公证。

## Validation / 验证

426 frontend tests, lint, and the production build passed. Native-window checks cover dragging, long-link recovery, domain avoidance, straight-line clearance, star compactness, saving, and reload. After a 1,000-unit hub drag, the eight-petal fixture retains its directions with a mean link length of 437, a longest/shortest ratio of 1.032, and no drop-point drift.

426 项前端测试、lint、生产构建以及桌面白板实测通过。实测将枢纽横移约 1,000 个画布单位后，八个邻居仍保持环绕，平均连线约 437，最长与最短相差约 3%，松手落点不回退，保存重启后位置一致。

`SHA256SUMS.txt` contains the application archive checksum.
