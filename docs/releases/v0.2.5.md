# PaperCanvas v0.2.5 — Now on Windows

PaperCanvas now runs on Windows 10/11 x64 as well as Apple Silicon Macs.
The Windows version shares the same paper library, canvas, PDF reader, highlights,
Markdown notes, mind maps, and embedded ChatGPT features as the macOS version.

PaperCanvas 现已支持 Windows 10/11 x64。Windows 与 macOS 共用同一套功能：
论文库、白板、PDF 阅读与标注、Markdown 笔记、思维导图和内嵌 ChatGPT。

Also fixes restoring the within-page reading position at a saved zoom level.
同时修复了恢复缩放比例时，PDF 页内阅读位置可能偏移的问题。

## Windows / Windows 下载

Download **`PaperCanvas-0.2.5-Windows-x64.zip`**, extract the entire archive,
and open **`PaperCanvas.exe`** inside `PaperCanvas-win32-x64`.
Keep the adjacent files and `resources` directory together. No installer,
administrator access, Node.js, Rust, or separate WebView2 install is required.

下载 Windows 压缩包并完整解压，打开文件夹中的 `PaperCanvas.exe` 即可。
支持 Intel/AMD 64 位电脑；本次未提供原生 Windows ARM64 包。
使用 Ctrl+F 搜索 PDF，Ctrl+B/I/K 编辑笔记；支持从资源管理器拖入 PDF。

Your library and notes live in **`%APPDATA%\com.papercanvas.desktop`**, separate
from the application folder. Quit PaperCanvas before replacing the app folder
to upgrade. The ZIP is portable for launching; user data is stored in AppData.
This community build is unsigned, so Windows may show a SmartScreen or
unknown-publisher prompt on first launch.

论文和笔记独立保存在上述 AppData 目录；升级时退出程序并替换应用文件夹即可。
本版本尚未进行 Windows 代码签名，首次启动可能出现系统安全提示。

## macOS / macOS 下载

**Apple Silicon (M1 or newer), macOS 13+.** Download
**`PaperCanvas-0.2.5-macOS-arm64.zip`**, quit the previous copy, and replace it
with the unzipped `PaperCanvas.app`. Existing local data stays in place.

This build is ad-hoc signed, without Apple Developer ID signing or notarization.
If macOS blocks the first launch and you trust the download, use **System Settings →
Privacy & Security → Open Anyway**. [Apple's instructions](https://support.apple.com/en-us/102445).

macOS 用户退出旧版后替换应用即可，现有论文、笔记和设置会保留。

## Validation / 验证

The release workflow builds each platform natively, runs frontend and desktop
boundary tests, checks the Rust backend and migrations, and runs a real Electron
window with synthetic PDFs and a local chat fixture. It covers PDF rendering,
search, annotations, note persistence, and embedded-view isolation. Backend
bridge tests include Chinese characters and spaces in file paths.

Windows 与 macOS 分别在原生 runner 上构建并测试。内嵌对话测试使用本地网页，
不验证真实 ChatGPT 账号登录；也不代表所有 Windows 硬件配置都已覆盖。

`SHA256SUMS.txt` contains checksums for both application archives.
