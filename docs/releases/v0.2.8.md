# PaperCanvas v0.2.8 — Linux and Ubuntu support

PaperCanvas now offers a Linux x64 desktop version, with Ubuntu 22.04 and 24.04 as the first supported distributions. It shares the paper library, canvas, PDF reader, annotations, Markdown notes, mind maps and embedded ChatGPT interface with Windows and macOS.

PaperCanvas 正式加入 **Linux x64 版**，优先支持 **Ubuntu 22.04 / 24.04**。论文库、画布、PDF 阅读与标注、Markdown 笔记、思维导图和内嵌 ChatGPT 与 Windows、macOS 共用同一套功能。

## Ubuntu installation / Ubuntu 安装

Download the `.deb`, then run from its download directory:

下载 `.deb` 后，在文件所在目录执行：

```sh
sudo apt install ./PaperCanvas-0.2.8-Linux-amd64.deb
```

Open **PaperCanvas** from the application menu, or run `paper-canvas` as your normal desktop user. The installer sets up the desktop icon and the application-specific AppArmor profile on Ubuntu 24.04. Node.js, Rust and WebKit development packages are not needed to run the release.

安装后从应用菜单打开 **PaperCanvas**，或以普通用户运行 `paper-canvas`。安装器会配置应用图标和 Ubuntu 24.04 所需的应用专用 AppArmor 规则，无需安装 Node.js、Rust 或 WebKit 开发依赖。

AppImage is an alternative for compatible desktops. See the installation guide for FUSE and sandbox requirements; the `.deb` is recommended on Ubuntu. Linux ARM64 is not included.

AppImage 供兼容桌面环境使用，FUSE 与沙箱要求见安装教程；Ubuntu 推荐使用 `.deb`。本次不提供 Linux ARM64 包。

## Updates and data / 更新与数据

- **Windows Setup and macOS:** use **Help → Check for Updates…**. Windows portable ZIP users replace the program manually.
- **Linux:** **Check for Updates… → View release** opens the release page. Quit the app, then install the new `.deb` or replace the AppImage.
- Linux data is stored at `$XDG_CONFIG_HOME/com.papercanvas.desktop`, defaulting to `~/.config/com.papercanvas.desktop`. Both formats share the library and Chromium sign-in profile.

升级前请正常退出应用。现有论文、笔记及登录资料保存在独立的数据目录中，替换程序会保留这些数据。Windows 安装版和 macOS 继续支持应用内更新；Linux 当前使用新版提示和手动安装。

## Validation / 验证

The release workflow builds Windows, macOS and Linux natively. It checks the frontend, desktop bridge and Rust backend, tests the installed `.deb` and AppImage on Ubuntu 22.04, and installs the same `.deb` on Ubuntu 24.04. Desktop checks cover PDF interactions, notes and reading-position persistence, clipboard text/images and embedded-view isolation using synthetic PDFs and a local chat fixture.

发布流程包含三个平台的原生构建与测试，以及 Ubuntu 22.04 / 24.04 安装验证。Linux 自动测试使用 X11；Wayland、中文输入法和真实 ChatGPT 账号登录尚待实机验证。

`SHA256SUMS.txt` covers all release files other than the checksum list itself. `latest.yml`, `.blockmap` and signed `appcast.xml` are used by the Windows and macOS updaters; ordinary installation does not require downloading them.
