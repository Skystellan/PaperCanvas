# PaperCanvas v0.2.9 — Ubuntu 20.04 compatibility

PaperCanvas Linux x64 now supports **Ubuntu 20.04**, alongside 22.04 and 24.04. ROS1 users can keep their existing system and ROS/Python environment. Linux packages are built on Ubuntu 20.04, with a glibc 2.31 compatibility check covering every shipped ELF binary. The Electron backend builds independently of the legacy Tauri/WebKit shell.

Linux x64 正式增加 **Ubuntu 20.04** 兼容支持，继续支持 22.04 / 24.04。ROS1 用户无需升级系统或改动 ROS、Python 环境。本版本也包含更清楚的应用内 ChatGPT 登录指引。

## Install and update / 安装与更新

On Ubuntu, download the DEB and run / Ubuntu 下载 DEB 后执行：

```sh
sudo apt install ./PaperCanvas-0.2.9-Linux-amd64.deb
```

Open PaperCanvas from the application menu as your normal desktop user. Linux DEB/AppImage, Windows Setup and macOS support **Help → Check for Updates…**. Linux downloads are verified before installation; restart and install preserves local papers, notes and sign-in data. Windows portable ZIP upgrades remain manual. The macOS community build is ad-hoc signed; Windows is unsigned. First-launch operating-system prompts still apply.

Linux DEB/AppImage、Windows 安装版和 macOS 均支持 **帮助 → 检查更新**。下载校验后选择「重启并安装」，本地论文、笔记和登录资料会保留。无法在 Ubuntu 20.04 启动的旧版 0.2.8，请直接安装上面的 DEB。之前使用 **0.2.9 测试包** 的用户也请手动安装正式包一次：版本号相同不会触发应用内更新。

## Validation / 验证范围

CI covers frontend and Rust tests, packaged Windows/macOS desktop tests, Ubuntu 20.04 container tests for both DEB and AppImage, and the same Linux packages on Ubuntu 22.04/24.04. Linux update tests reject damaged downloads, install, relaunch and verify retained data. Ubuntu 20.04 container validation shares the host kernel; early user trial feedback is positive, but hardware graphics, input methods and live ChatGPT sign-in vary by machine. Ubuntu 20.04 compatibility is maintained by this project, outside Electron's current official distribution support policy.

CI 已覆盖 Ubuntu 20.04 容器中的 DEB/AppImage 桌面功能与更新、22.04/24.04 同包回归，以及 Windows/macOS 桌面测试。已收到 20.04 用户初步可用的反馈；具体显卡、输入法、真实 ChatGPT 登录仍与机器环境有关。[Ubuntu 20.04 兼容说明](https://github.com/Skystellan/PaperCanvas/blob/v0.2.9/docs/ubuntu-20.04.md)

`SHA256SUMS.txt` covers the release files. `latest-linux.yml`, `latest.yml`, `.blockmap` and signed `appcast.xml` are updater files; ordinary installation does not require downloading them.
