# PaperCanvas v0.3.0 — Research MCP and online PDF reading

Search with Codex or Claude Code, bring candidate papers and tentative connections onto the canvas, then read arXiv PDFs on demand. PaperCanvas imports metadata first and saves PDF files only when you choose **保存离线 (Save offline)**.

使用 Codex 或 Claude Code 自带的搜索能力初筛论文，将候选论文和建议连线直接导入画布，再按需在线阅读 arXiv PDF。导入时仅保存元数据；点击 **保存离线** 才写入本地 PDF。

## What changed / 更新内容

- **Research MCP:** local stdio tools import batches and read scoped context. Independent searches do not read your existing canvas; selected-paper and gap-analysis requests explicitly opt into limited metadata. Imports deduplicate by source identifiers, preserve existing layouts and label AI-suggested connections. The **AI 导入** panel can undo unchanged imported cards and links while retaining library papers and notes.
- **Online arXiv reading:** open a candidate in the existing PDF.js reader with search, highlights and bookmarks. PDF bytes stay in memory until the reader closes, with a 50 MiB per-document limit. Explicit offline saving keeps the same paper, notes and canvas links. Version and content checks protect annotations from changed documents.
- **Shared workspace service:** the desktop and research tools use the same native transactions and validation. Revision checks protect existing canvas edits from stale writes.

- **研究 MCP：** 支持批次导入与按意图读取上下文。独立搜索不会读取已有画布；基于选中论文和查找图谱缺口时才返回受限信息。按来源标识去重，保留现有布局，建议连线明确标注为 AI 初筛。“AI 导入”可撤回尚未修改的批次卡片与连线，保留论文和笔记。
- **arXiv 在线阅读：** 复用现有 PDF 阅读器，支持搜索、批注和书签。文档仅保留内存，关闭后释放，单篇上限 50 MiB；显式保存离线后保留同一篇论文及其内容。版本和内容检查避免旧批注对应到变化后的 PDF。
- **统一工作区服务：** 桌面与研究工具复用原生事务和校验，画布版本检查防止旧状态覆盖新修改。

## Try it / 开始使用

See [MCP setup / MCP 连接说明](https://github.com/Skystellan/PaperCanvas/blob/v0.3.0/mcp/README.md). The release bundles `papercanvas-mcp.mjs` in the application's resources directory; external MCP clients require Node.js 22.12 or newer. Keep PaperCanvas open while using these tools.

发布包在应用 resources 目录包含 `papercanvas-mcp.mjs`，外部 MCP 客户端需要 Node.js 22.12+，使用工具时保持 PaperCanvas 打开。内嵌 ChatGPT 网页尚未接入此工具链。在线 PDF 首版支持 arXiv；其他来源显示元数据和来源链接。

## Install and update / 安装与更新

Linux DEB/AppImage, Windows Setup and macOS users can upgrade through **Help → Check for Updates…**. Existing papers, notes and sign-in profiles are retained. Windows portable ZIP users replace the program folder manually. The macOS community build is ad-hoc signed; Windows is unsigned. First-launch operating-system prompts still apply.

Linux DEB/AppImage、Windows 安装版和 macOS 可通过 **帮助 → 检查更新** 升级，保留现有论文、笔记与登录资料。Windows 便携版请手动替换程序。

## Validation / 验证范围

Tests cover transactional imports, identity deduplication, intent boundaries, rollback and revision conflicts; online-document cancellation, limits and content changes; and offline attachment without replacing existing files or losing annotations. Packaged desktop tests exercise real MCP → Electron → Rust and PDF.js with isolated profiles and synthetic network responses. Existing desktop and updater workflows cover macOS, Windows and Ubuntu compatibility. They do not validate live ChatGPT sign-in or guarantee availability of external paper sources.

验证覆盖导入事务、标识去重、意图边界、撤回与版本冲突，以及在线文档取消、大小限制、内容变更保护和离线保存。打包后的应用使用隔离资料与合成网络响应验证真实 MCP 和 PDF.js 流程；原有桌面及更新测试继续覆盖 macOS、Windows 和 Ubuntu。测试不验证真实 ChatGPT 登录，也不保证外部论文来源持续可用。

`SHA256SUMS.txt` covers release assets. `latest-linux.yml`, `latest.yml`, `.blockmap` and the signed `appcast.xml` support in-app updates.
